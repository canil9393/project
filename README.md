 Patient History Management System

A web-based Patient History Management System developed using **PHP, MySQL, HTML, CSS, JavaScript**. The application enables healthcare providers to securely manage patient records, medical history, appointments, and prescriptions through a centralized platform.

## 🌐 Live Demo

🔗 **Website:** https://anil9392.42web.io

---

## 📌 Features

- 👤 Patient Registration
- 🔐 Secure User Login
- 🩺 Doctor Dashboard
- 📋 Patient History Management
- 💊 Prescription Management
- 📅 Appointment Scheduling
- 🔍 Search Patient Records
- ✏️ Edit & Delete Patient Information
- 📄 Digital Medical Records
- 🔒 Secure Database Connectivity

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Server:** Apache (XAMPP)
- **Hosting:** InfinityFree
